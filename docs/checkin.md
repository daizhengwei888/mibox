# 签到助手

把每天要签到的网站交给谜盒：批量加进来，一键全部签到，或者每天定时自动签。插件在你自己的浏览器里打开网页、点按钮、确认结果，用的是你已经登录的状态；需要登录时可以用保险箱里的账号。

![签到助手](images/checkin.png)

## 开始用

1. 「工具 › 签到助手 › 批量添加」，三种来源任选：
   - **粘贴网址**：每行一个，网址前后可以写名称；只填首页也行，插件会自己找签到入口；
   - **从收藏分组选**：星标或任意分组，可以全选、全不选、单个勾选；
   - **当前打开的网页**。
   已经在列表里的网址会跳过。添加时浏览器会一次性询问这些网站的访问权限。
2. 点「一键全部签到」。插件开一个最小化的窗口，同时签 1–5 个网站（「一次签」里选），页面上实时显示进度，可以随时停止。
3. 跑完后，顶部列出「需要处理」的网站和原因：授权、解锁保险箱、添加账号、打开网页、重试，或者「重试这 N 个」。不在签到页时，工具栏图标上的数字就是需要处理的网站数。
4. 「每天自动签到」选一个时间，就会每天在这个时间只跑今天还没成功的网站。电脑关着时错过的会在下次打开浏览器后补跑；失败的当天过 10 分钟再试，最多两次。

## 自动识别是怎么找按钮的

每个网站默认「自动识别」，按这个顺序：

1. **记住的做法**：成功过一次的网站，下次直接照着点，包括「先进签到页再点」这种多步的；中间的入口今天消失了，就直接去下一步的网页。保险箱锁着、没配 AI 时照样能用。
2. **今天已经签过**：页面上写着「今日已签到 / 明日再来 / 已领取」，或者签到按钮已经变灰，就记为已签过，不再点。
3. **按文字找按钮**：签到、打卡、报到、领取今日奖励、Daily Check-in 等，按匹配程度打分；避开「签到规则 / 签到记录 / 签到排行 / 补签 / 退出 / 注册 / 充值」这类入口。单页应用的按钮晚一点才出现时，会等一会儿再找。
4. **常见论坛**：NexusPHP（打开 `attendance.php` 即签到）、Discuz!（`dsu_paulsign` 会选心情、填一句话再提交；`k_misign`）、V2EX（`/mission/daily`）。
5. **交给 AI**：上面都找不到时，用你自己的 AI 接口一步一步决定点哪个元素（最多 5 步）。比如先打开「我的」菜单，再进「每日任务」，再点「领取」。

点完怎么算成功：页面上**新出现**了「签到成功、+5 积分、已签到、恭喜」这类字样（按句子逐个比较点之前和之后），或者点过的按钮消失、变灰、变成「已签到」，或者弹出的提示框这么说。网页明确说「签到失败 / 请稍后再试」时记为失败，并带上网页的原话。只是进了签到页（页面上还有没点的签到按钮）不算成功。

后台标签页里的 `alert` / `confirm` 会被接管（确认框一律按「确定」），不会卡住页面。

## AI 兜底

在保险箱新建一条「密钥和令牌」，展开「这是一个 AI 接口」，填 OpenAI 兼容的接口地址（比如 `https://api.openai.com/v1`、DeepSeek、通义千问、本地 Ollama 的 `http://localhost:11434/v1`）和模型名，再勾选「给签到助手用」。签到页上的「找不到时交给 AI」可以随时关掉。

发给 AI 的只有：任务名称、当前网址（不含查询参数）、页面标题、和签到有关的短文字（最多 30 条），以及带编号的可点元素列表（按钮、链接上的文字和少量属性，参考 [page-agent](https://github.com/alibaba/page-agent) / [browser-use](https://github.com/browser-use/browser-use) 的格式）。**不发**输入框里的内容、账号、密码、Cookie。AI 选到退出、注销、删除、付款、购买、充值、发帖、回复这类元素会被拒绝。

AI 每一步只回答一个 JSON：

```json
{"action": "click", "index": 5, "why": "签到按钮"}
{"action": "done", "result": "ok"}
{"action": "done", "result": "already"}
{"action": "login"}
{"action": "fail", "why": "页面上没有签到入口"}
```

## 需要登录、验证码

- 任务的「需要登录时」默认是「自动使用保险箱里这个网站的账号（只有一个时）」，也可以指定某一条，或者不登录。自动登录要求保险箱是解锁的；锁着时这个网站会跳过并提示。
- 遇到 Cloudflare 等待页、人机验证、reCAPTCHA / hCaptcha / Turnstile 验证码，插件**不会尝试绕过**，记为「需要人工验证」。打开网页手动通过一次后再重试。

## 自己点选按钮

「单个添加」时可以选「到页面上点选按钮，自己设定怎么算成功」：插件打开网页，鼠标移到按钮上点一下就记住了；成功条件可以是按钮消失或变灰、页面出现某段文字、页面出现某个地方、网址里出现某段内容。点选的按钮失效时，勾选「按自动识别再找一遍」的话会按上面的顺序找，并记住新做法。

编辑自动识别的任务时，可以「忘掉」记住的做法，下次重新找。

## 技能包

技能包是一份 JSON 步骤清单，只能打开网页、等待、点击和检查文字，读不到保险箱。导入后默认关闭，启用时会请你授权它声明的网站。

```json
{
  "format": "shuqian-skill/1",
  "name": "示例：每日领取",
  "description": "打开页面，点「领取」，确认出现「已领取」",
  "sites": ["https://example.com"],
  "schedule": "daily",
  "steps": [
    { "do": "open", "url": "https://example.com/daily" },
    { "do": "wait", "ms": 1000 },
    { "do": "click", "selector": "button.claim", "text": "领取" },
    { "do": "waitFor", "text": "已领取", "timeout": 8000 },
    { "do": "checkText", "text": "已领取" }
  ]
}
```

- `sites`：会访问的网站（只写到域名）。`open` 的网址必须在这些网站内。
- `schedule`：`daily` 跟签到助手一起每天运行，`manual` 只手动运行。
- 步骤最多 40 个，`wait` / `waitFor` 最长 30 秒。

## 测试

`tests/e2e/mock-sites.mjs` 里有 50 个模拟网站（直接按钮、先进签到页、单页应用、NexusPHP、Discuz、V2EX 风格、已签过、需要登录、人机验证、`alert` / `confirm`、晚出现的按钮、慢网站、打不开、只能靠 AI 的入口）和一个模拟 AI 接口。`npm run e2e:checkin` 会跑三轮：第一天、同一天再跑一次（应全部「今天已签过」）、第二天按记住的做法，并检查发给 AI 的内容里没有账号和密码。
